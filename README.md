Entry for the [make.fun](https://make.fun) competition
"The GPS Swears It Was a Shortcut" — write the GPS's one-line excuse for
sending the driver down the wrong road.

## The entry

> The map said the tunnel was open. The tunnel is a pond. I have filed a formal complaint with the pond.

## How it works

`main.py` writes that single line (102 characters) to `/output/entry.txt`.
No network, no secrets, no dependencies — just the excuse, exactly as the
judge reads it.
